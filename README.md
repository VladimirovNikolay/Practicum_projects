# Y.Afisha User Activity Analysis

Анализ пользовательской активности сервиса Яндекс.Афиша.  
Проект выполнен в рамках курса «Аналитик данных» Яндекс Практикума.

---

# Project Overview

Цель проекта — исследовать поведение пользователей сервиса, рассчитать ключевые продуктовые метрики и определить факторы, влияющие на выручку.

В рамках анализа были рассчитаны метрики активности, проведена сегментация пользователей и построен аналитический дашборд.

---

# Tech Stack

SQL  
Python (pandas, numpy, matplotlib, seaborn)  
Yandex DataLens  

---

# Dataset

Данные включают:

- логи пользовательских действий
- информацию о заказах и билетах
- временные метки событий

Объём данных — десятки тысяч событий.

---

# Key Metrics

В ходе анализа были рассчитаны:

- DAU / WAU / MAU
- Retention по когортам
- ARPU / ARPPU
- средний чек
- конверсия из просмотра в покупку

---

# Analysis

Основные этапы анализа:

1. Предобработка данных  
   - проверка структуры таблиц  
   - поиск дубликатов и аномалий  

2. Исследовательский анализ  
   - динамика активности пользователей  
   - сезонность по дням недели и времени суток  

3. Сегментация пользователей  
   - анализ  
   - выделение активных и неактивных сегментов  

4. Визуализация результатов  
   - построение графиков  
   - создание интерактивного дашборда

---

# Key Insights

- выявлены периоды максимальной активности пользователей  
- определены сегменты с наибольшим вкладом в выручку  
- обнаружены временные интервалы с низкой конверсией  
- предложены гипотезы для роста retention и увеличения конверсии
